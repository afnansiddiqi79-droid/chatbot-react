# 🤖 React Chatbot

A simple and interactive chatbot application built with React. This project was created to practice React fundamentals, components, state management, event handling, and dynamic UI updates.

## 📖 Project Overview

This is a simple chatbot application where users can send messages and receive responses from the chatbot.

The project helped me practice React concepts such as components, props, useState, useEffect, useRef, event handling, conditional rendering, array mapping, and dynamic UI updates.

## 🛠️ Technologies Used

- React
- JavaScript
- HTML5
- CSS3

## ✨ Main Features

- Interactive chatbot interface
- Send messages through the input field
- Automatic chatbot responses
- User and robot message styling
- User and robot profile images
- Automatically scrolls to the latest message
- Dynamic chat message rendering
- Clean and simple user interface

## ⚛️ React Concepts Practiced

- React Components
- Props
- useState
- useEffect
- useRef
- Event Handling
- Conditional Rendering
- Array Mapping
- Dynamic UI Updates

## 📦 Dependencies

- React
- ReactDOM
- SuperSimpleDev Chatbot
- Babel

The project uses CDN-based dependencies, so no npm install is required.

## 🚀 How to Run Locally

1. Clone the repository:

   git clone https://github.com/afnansiddiqi79-droid/chatbot-react.git

2. Open the project folder:

   cd chatbot-react

3. Open the index.html file in your browser.
